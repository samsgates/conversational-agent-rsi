# Domain pack guide

A pack contains `manifest.yaml`, state schema, actions, transitions, prompt templates, personas, scenarios, rubrics, deterministic rules, tools, dashboards, seed knowledge, tests, and README.

Pack state extensions are namespaced. Actions define preconditions and expected changes. Scenarios separate visible briefing from hidden truth and specify split, persona, goals, failure conditions and max turns. Evaluation rubrics reference versioned evaluator adapters.
